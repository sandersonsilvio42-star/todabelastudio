# Toda Bela Studio 💇‍♀️✨

O **Toda Bela Studio** é uma aplicação web moderna desenvolvida para otimizar o atendimento, a apresentação de serviços e a experiência de agendamento dos clientes de um estúdio de beleza. 

Este projeto foi construído focado em uma interface responsiva, limpa e de alta conversão, simulando perfeitamente as demandas de um negócio real. Ele opera em conjunto com o painel administrativo [adm-todabelastudio](https://github.com) para o gerenciamento completo do estúdio.

## 🚀 Link do Projeto
Confira a aplicação rodando em produção: https://todabelastudio.vercel.app/

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização moderna, layouts flexíveis (Flexbox/Grid) e design totalmente responsivo para dispositivos móveis.
* **JavaScript:** Lógica de interatividade, manipulação do DOM e dinamismo na navegação do usuário.
